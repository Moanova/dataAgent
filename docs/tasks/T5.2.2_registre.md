## Décisions / constats
- La persistance fonctionne par **instance + chemin** : chaque `RegistreSourcesInaccessibles(chemin)` charge le JSON existant, les fonctions cœur (`rechercher_jeux`, `telecharger_brut`) appellent `sauvegarder()` après chaque consignation — le cycle rechargement/enrichissement est sain.
- Écart documenté (pas un défaut) : le **re-test effectif** d'une source en échec technique (relancer le téléchargement d'une ressource déjà au registre) n'est pas implémenté comme mécanisme dédié — le registre ne bloque pas, mais rien ne déclenche automatiquement le re-essai. Conforme au contrat (autorisation, pas obligation) ; le réessai intelligent est déjà au kanban (T7.1).
