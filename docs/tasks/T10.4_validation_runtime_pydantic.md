## Implémentation
- `src/contracts/{rechercher_jeux,lister_ressources,interroger_ressource,telecharger_brut}.py` : `model_config = ConfigDict(extra="ignore")` sur les 4 classes `*Input` — les champs inconnus envoyés par l'agent sont ignorés silencieusement.
- `src/agent/outils.py` (réécrit, v2) :
  - nouvelle table `MODELES_INPUT` remplaçant `ARGUMENTS_OBLIGATOIRES` et `FILTRES_OPTIONS` (supprimés, avec `_valider_arguments` et `_arguments_positionnels`) ;
  - `Input.model_validate(arguments_dict)` : `ValidationError` → `erreur_parametres` avec message condensé par champ (`_resume_erreurs`), jamais d'exception vers l'agent ;
  - options construites par `valide.model_dump(exclude_unset=True)` : seuls les champs fournis par l'agent sont transmis au cœur, en types natifs (sous-modèles `filtre`/`tri` reconvertis en dict) ;
  - `options.setdefault("id_execution", id_execution)` conservé **après** validation : `id_execution` reste hors des modèles (identifiant de flux interne), celui de la boucle prime, celui de l'agent est ignoré (via `exclude_unset`).
- `src/contracts/validation_api.py` : docstring corrigée — « les modèles Pydantic valident les tool_calls au runtime (`executer_outil`) et la couche sortante en tests de cohérence » (la divergence documentée est levée).

## Gain sémantique
Validation amont désormais complète : bornes numériques (`limite` 1-20, `page` ≥ 1, `taille_page` 1-50), vocabulaires fermés (enums T10.5 via sous-modèles `FiltreColonne`/`TriColonne`), types imbriqués — et messages d'erreur citant le champ fautif, exploitables par l'agent pour se corriger (section s3 du prompt).

## Tests
- `tests/unit/test_boucle.py` : 5 nouveaux tests — bornes numériques, sous-modèle `tri` hors vocabulaire, champ superflu ignoré, champs absents non transmis, message d'erreur citant le champ fautif.
- Non-régression : TU-B1..B3, TI-14b et suite complète inchangés et verts (263 tests).

## Décisions de conception
- `exclude_unset=True` plutôt que filtrage sur `model_fields` : reproduit exactement l'ancienne sémantique (champs fournis uniquement) et garantit des types natifs pour le cœur.
- `registre` (paramètre de `rechercher_jeux`) reste hors modèle : interne/test-only, jamais fourni par l'agent ni la CLI.
