# T10.5 — Vocabulaires fermés déplacés vers le cœur

## Statut
- [X] Implémentation
- [X] Tests unitaires
- [ ] Validation (tâche en cours au kanban)

## Objectif
Source unique de vérité pour les vocabulaires fermés échangés entre CLI, agent et cœur ; suppression des listes dupliquées dans `src/main.py`.

## Implémentation
- Nouveau module `src/core/vocabulaires.py` : StrEnum `TriRecherche`, `FenetreMaj`, `OperateurFiltre`, `OrdreTri` + constante `APERCU_DEFAUT = 5` + helper `valeurs(enum)`.
- `src/contracts/rechercher_jeux.py` et `src/contracts/interroger_ressource.py` : définitions d'enum supprimées, ré-import depuis `src.core.vocabulaires` (identité des classes préservée — les tests de contrats TU-08 restent verts sans modification).
- `src/main.py` :
  - suppression de `TRIS`, `OPERATEURS_FILTRE`, `ORDRES_TRI`, `FENETRES_MAJ` ;
  - gardes CLI via `valeurs(...)` ;
  - nouvelle option `--apercu N` sur `query` (défaut `APERCU_DEFAUT = 5`, `min=0`) qui borne l'affichage des lignes ;
  - aide `--id-execution` dédupliquée via la constante `AIDE_ID_EXECUTION` (5 commandes).

## Tests
- `tests/unit/test_cli.py` : 3 nouveaux tests — valeurs des vocabulaires au cœur, identité StrEnum contrats ↔ cœur, plafond d'affichage `--apercu` (défaut 5 et valeur 2).
- Suite complète : 258 verts.

## Décisions
- Les StrEnum vivent dans le cœur (pas dans les contrats) : le cœur n'importe jamais `src/contracts/`, et la CLI ne doit pas dépendre des contrats. Les contrats ré-importent depuis le cœur, garantissant zéro divergence (test d'identité `is`).
- `valeurs(enum)` préféré à `[e.value for e in Enum]` épars dans le code CLI.
