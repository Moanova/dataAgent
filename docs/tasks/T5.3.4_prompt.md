# Suivi T5.3.4 — Prompt système (A1–A4)

## Statut
- **T5.3.4** : ✅ Terminé (14/10/2026) — évaluation des propriétés TA sur conversations réelles restant en local (itératives)

## Implémentation
`PROMPT_SYSTEME` dans `src/agent/agent.py` : prompt structuré (~750 mots, français), sections :
- Rôle + les 4 étapes agentiques (A1 reformulation, A2 sélection, A3 tranchage, A4 synthèse).
- RÈGLES GÉNÉRALES : langue, les 4 outils, les 7 codes de statut avec action attendue (contrat_global), intégrité des identifiants (TA-01), ordre des étapes (TA-02), économie d'invocations/plafond (TA-05), licence et attribution.
- A1 : 2-4 mots-clés courts (logique ET), reformulation, stratégies élargir/affiner, tri, fenêtre de mise à jour, pagination.
- A2 : critères de sélection (fraîcheur, organisation officielle, ressources exploitables), justification dans le raisonnement, sobriété.
- A3 : autoportance de la réponse (pas d'appel d'outil), contradictoire ≠ ambigu (sémantique T3.2.3), décision consignée dans le raisonnement, le code garde sa classification.
- A4 : mémorisation des exclusions en cours de flux, suggestion fichier_heberge_exterieurement → alternative plutôt que relance, rapport final structuré en 4 points (acquisitions + licences, retenues, écartées + motifs, limites).
- PAGINATION ET VOLUMES : page_suivante (recherche et interrogation, filtres/tris stables entre pages), volume_eleve_telechargement_brut_suggere → bascule telecharger_brut, telecharger_brut réservé aux ressources sélectionnées.

## Décisions de rédaction
- ~750 mots (cible 400-600, dépassement accepté : couverture des 7 codes de statut avec leur action attendue, exigée par le contrat global).
- Sans accents dans le corps du prompt (cohérent avec le style du dépôt).
- Le prompt prescrit des comportements, ne duplique pas les descriptions d'outils (les contrats JSON restent la source de vérité envoyée à l'API).
- Garde-fou T5.3.1 inchangé : l'empreinte sha256 du prompt reste la référence stricte de réutilisation d'agent persistant (tout changement du prompt invalidera automatiquement un agent console existant).
