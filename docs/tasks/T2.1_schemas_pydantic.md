# T2.1 : Schemas Pydantic pour les contrats

## Statut
- [X] Planification
- [X] Implementation
- [X] Tests unitaires
- [X] Tests de contrat (TC)

## Objectif
Creer les schemas Pydantic v2 dans `src/contracts/` qui formalisent les contrats
d'entree/sortie des quatre outils exposes aux agents, en miroir fidele des
fichiers JSON existants dans `contrats/`.

## Fichiers crees
- `src/contracts/__init__.py` — Exports publics du package
- `src/contracts/base.py` — Modeles communs (StatutEnum, ReponseBase, JeuResume, RessourceResume, valider_coherence_contrat)
- `src/contracts/rechercher_jeux.py` — RechercherJeuxInput / RechercherJeuxOutput + enums (TriRecherche, FenetreMaj)
- `src/contracts/lister_ressources.py` — ListerRessourcesInput / ListerRessourcesOutput + re-export ClasseRessource
- `src/contracts/interroger_ressource.py` — InterrogerRessourceInput / Output + FiltreColonne, TriColonne, enums (OperateurFiltre, OrdreTri)
- `src/contracts/telecharger_brut.py` — TelechargerBrutInput / TelechargerBrutOutput
- `tests/unit/test_contracts.py` — 53 tests (TU-25 a TU-28, TC-01 a TC-05, validation modeles)

## Fichiers modifies (corrections de contrats JSON)
- `contrats/lister_ressources.json` — Ajout description pour `id_jeu` et `donnees.ressources`
- `contrats/interroger_ressource.json` — Ajout descriptions pour `id_ressource`, `filtre`, `tri` et leurs sous-proprietes
- `contrats/telecharger_brut.json` — Ajout description pour `id_ressource`
- `contrats/rechercher_jeux.json` — Ajout description pour `donnees.jeux`
