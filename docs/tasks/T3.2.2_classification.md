## Choix de conception actés
- **Liste fermée** des formats connus (tabulaires : csv, xlsx, xls, tsv ; autres : zip, geojson, json, shp, pdf, parquet) — tout le reste va en `indetermine` où l'agent tranche (A3).
- **Ordre de priorité** des signaux en conflit : HTML > API > tabulaire > autre. Le cas mime HTML + URL /api va en `page_web` (ordre strict).
- L'étape A3 (tranchage agentique des `indetermination`) est hors périmètre code : comportement de l'agent, non un outil.
